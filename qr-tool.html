How to use

  1. Enter the event name, date, gallery URL, and access code (or auto-generate one).
  2. Click "Generate QR Code" to create the QR code and access code card.
  3. Download the card as an image — it shows both the QR code and the access code together.
  4. Show this QR code and access code to your customer. They scan to reach their gallery.
  5. The customer uses their access code to identify their photos when purchasing.
